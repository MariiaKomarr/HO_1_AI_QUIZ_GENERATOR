# AI Quiz Generator

**AI Quiz Generator** — консольний Python-застосунок для автоматичного створення тестових завдань на основі навчальних матеріалів із використанням хмарного Google Gemini API.

## Можливості

- Завантаження навчальних матеріалів у форматах PDF, DOCX і TXT.
- Автоматична генерація тестових питань за допомогою AI.
- Інтерактивне проходження тестування в терміналі.
- Автоматична перевірка відповідей.
- AI-аналіз помилок та персональні рекомендації.
- Збереження результатів у JSON.
- Перегляд історії тестувань та статистики.

## Використані технології

- Python 3
- Google Gemini API
- Google Gen AI SDK
- PyMuPDF
- python-docx
- python-dotenv

## Встановлення

1. Клонувати репозиторій.
2. Створити віртуальне середовище:

   `python -m venv .venv`

3. Активувати середовище в Windows PowerShell:

   `.\.venv\Scripts\Activate.ps1`

4. Встановити залежності:

   `pip install -r requirements.txt`

5. Створити файл `.env` та додати власний API-ключ:

   `GEMINI_API_KEY=your_api_key`

6. Запустити програму:

   `python main.py`

## Як працює застосунок

1. Користувач вказує шлях до навчального документа.
2. Python зчитує текст документа.
3. Gemini API генерує тестові питання.
4. Користувач проходить тест у терміналі.
5. Python підраховує результат.
6. Gemini аналізує помилки та формує рекомендації.
7. Результати зберігаються у папці `results`.

## Хмарна складова

Застосунок використовує Google Gemini API для обробки навчального тексту, генерації питань та аналізу результатів.

Запити надсилаються до хмарної AI-моделі, тому для роботи потрібне підключення до інтернету та чинний API-ключ.

## Обмеження

- Для сканованих PDF без текстового шару потрібне OCR.
- Якість тестових питань залежить від якості навчального матеріалу.
- AI-відповіді можуть містити неточності.
- Для дуже коротких конспектів кількість питань може бути меншою за 10.

## Результати

Програма зберігає згенерований тест і результати проходжень у форматі JSON, що дозволяє переглядати історію навчання.
