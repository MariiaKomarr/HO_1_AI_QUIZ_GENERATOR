# AI Quiz Generator

**AI Quiz Generator — інтелектуальна вебсистема для автоматичного створення та оцінювання тестів на основі навчальних матеріалів із використанням Gemini AI та хмарних сервісів Google Cloud.**

Проєкт розроблено в межах навчальної роботи з хмарних обчислень.

**Виконала:** Комар Марія, група ТК-41.

## 1. Опис проєкту

AI Quiz Generator — це вебзастосунок, який дозволяє завантажувати навчальні матеріали, автоматично генерувати тестові запитання за допомогою штучного інтелекту, проходити тестування та отримувати результати з поясненнями.

Система використовує Gemini AI для створення запитань і формування рекомендацій, а Google Cloud Firestore — для збереження результатів тестування.

Застосунок реалізовано мовою Python із використанням Flask та розгорнуто в Google Cloud Run у Docker-контейнері.

## 2. Основні можливості

- Завантаження навчальних матеріалів у форматах PDF, DOCX і TXT.
- Автоматична генерація тестових запитань за допомогою Gemini AI.
- Вибір кількості запитань від 1 до 30.
- Інтерактивне проходження тестів у браузері.
- Автоматична перевірка відповідей.
- Розрахунок кількості правильних відповідей і відсотка успішності.
- Відображення правильних відповідей та пояснень.
- AI-аналіз результатів і рекомендації для подальшого навчання.
- Збереження результатів у Google Cloud Firestore.
- Перегляд історії тестувань та статистики.
- Робота у хмарному середовищі Google Cloud Run.
- Обмежений доступ до хмарного застосунку через Google Cloud IAM.

## 4. Архітектура системи

Система використовує клієнт-серверну архітектуру з інтеграцією хмарних сервісів.

**Схема взаємодії компонентів:**

```text
Користувач
    |
    v
Веббраузер
    |
    v
Google Cloud Run
    |
    v
Flask Web Application
    |
    +----> Document Reader
    |         |
    |         +----> PDF / DOCX / TXT
    |
    +----> Gemini AI
    |         |
    |         +----> Генерація запитань
    |         +----> Аналіз результатів
    |
    +----> Google Cloud Firestore
    |         |
    |         +----> Активні тести
    |         +----> Історія результатів
    |
    +----> Google Secret Manager
              |
              +----> Gemini API Key
              +----> Flask Secret Key
```

### Принцип роботи

1. Користувач завантажує навчальний документ через вебінтерфейс.
2. Flask отримує файл і передає його модулю читання документів.
3. Текст документа передається до Gemini AI.
4. Gemini AI формує тестові запитання з варіантами відповідей.
5. Активний тест тимчасово зберігається у Firestore.
6. Користувач проходить тестування.
7. Flask перевіряє відповіді та обчислює результат.
8. Gemini AI формує аналіз помилок і рекомендації.
9. Результат зберігається у Firestore.
10. Користувач може переглянути історію тестувань і статистику.

## 6. Локальний запуск

### 6.1. Клонування репозиторію

```bash
git clone https://github.com/MariiaKomarr/HO_1_AI_QUIZ_GENERATOR.git
cd HO_1_AI_QUIZ_GENERATOR
```

### 6.2. Створення віртуального середовища

```bash
python -m venv .venv
```

Активація у Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

### 6.3. Встановлення залежностей

```bash
pip install -r requirements.txt
```

### 6.4. Налаштування змінних середовища

Створити файл `.env`:

```env
GEMINI_API_KEY=your_gemini_api_key
FLASK_SECRET_KEY=your_random_secret_key
```

Для роботи з Firestore локально необхідно налаштувати Google Cloud Application Default Credentials:

```bash
gcloud auth application-default login
gcloud auth application-default set-quota-project ai-quiz-generator-511621
```

Також потрібні відповідні права доступу до Firestore.

### 6.5. Запуск вебзастосунку

```bash
python app.py
```

Відкрити в браузері:

`http://127.0.0.1:5000`

### 6.6. Запуск консольної версії

```bash
python main.py
```

## 7. Розгортання в Google Cloud

Хмарний застосунок розгорнуто в проєкті:

**Google Cloud Project ID:** `ai-quiz-generator-511621`

**Регіон:** `europe-west3` (Frankfurt)

**Cloud Run Service:** `ai-quiz-generator`

**Artifact Registry Repository:** `ai-quiz-repo`

### 7.1. Збирання Docker-образу

```bash
gcloud builds submit --tag europe-west3-docker.pkg.dev/ai-quiz-generator-511621/ai-quiz-repo/ai-quiz-generator:v1
```

### 7.2. Розгортання в Cloud Run

```bash
gcloud run deploy ai-quiz-generator \
  --image=europe-west3-docker.pkg.dev/ai-quiz-generator-511621/ai-quiz-repo/ai-quiz-generator:v1 \
  --region=europe-west3 \
  --service-account=ai-quiz-run@ai-quiz-generator-511621.iam.gserviceaccount.com \
  --no-allow-unauthenticated \
  --set-secrets=GEMINI_API_KEY=gemini-api-key:latest,FLASK_SECRET_KEY=flask-secret-key:latest \
  --memory=1Gi \
  --cpu=1 \
  --min-instances=0 \
  --max-instances=1
```

Команди наведені для Bash. У Windows PowerShell команду розгортання можна записати одним рядком.

### 7.3. Приватний доступ

Сервіс налаштовано без анонімного доступу.

Для виклику застосунку використовується роль `roles/run.invoker`.

Для локального доступу до хмарної версії:

```bash
gcloud run services proxy ai-quiz-generator --region=europe-west3 --port=8080
```

Після запуску проксі застосунок доступний за адресою:

`http://localhost:8080`

Це локальна адреса захищеного проксі, а не публічне посилання для всіх користувачів.

## 8. Google Cloud Firestore

Firestore використовується для зберігання даних вебзастосунку.

### Колекція `active_quizzes`

Містить дані активних тестувань:

- `questions` — згенеровані запитання;
- `source_text` — текст навчального матеріалу;
- `document_name` — назва документа;
- `created_at` — дата створення;
- `expires_at` — час завершення дії тесту.

### Колекція `quiz_results`

Містить результати завершених тестувань:

- `document` — назва документа;
- `percentage` — відсоток правильних відповідей;
- `correct_answers` — кількість правильних відповідей;
- `total_questions` — загальна кількість запитань;
- `mistakes` — список помилок;
- `created_at` — дата та час тестування.

На основі цих даних вебзастосунок обчислює кількість тестувань, середній та найкращий результати.

## 10. Результати тестування

Роботу системи перевірено в Google Cloud Run.

Під час тестування підтверджено:

- Успішний запуск вебінтерфейсу через захищений проксі.
- Генерацію тестових запитань на основі навчального документа.
- Коректну перевірку відповідей.
- Відображення результату 4/5 — 80%.
- Збереження результату в Google Cloud Firestore.
- Завантаження історії тестувань із Firestore.

На момент перевірки в історії відображалися:

| Показник | Значення |
|---|---|
| Кількість тестувань | 4 |
| Середній результат | 70% |
| Найкращий результат | 100% |

Ці показники є результатами демонстраційного тестування, а не фіксованими характеристиками системи.
